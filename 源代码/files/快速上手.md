# 思维导图代码上手指南

## 一、代码架构概览

### 1. 核心架构（MVC模式）

```
main.py (入口)
    ↓
mainwindow.py (视图层 - View)
    ↓
Graph.py (模型层 - Model/Controller)
    ↓
Node.py + Branch.py (数据层 - Data)
    ↓
Command.py (命令模式 - 撤销/重做)
```

### 2. 关键文件说明

| 文件 | 作用 | 关键类/函数 |
|------|------|------------|
| `main.py` | 程序入口 | `main()` - 初始化应用和窗口 |
| `mainwindow.py` | 主窗口 | `MainWindow` - 菜单、工具栏、状态栏 |
| `Graph.py` | 场景管理 | `Graph` - 管理所有节点和连接线 |
| `Node.py` | 节点实现 | `Node` - 节点的绘制、编辑、移动 |
| `Branch.py` | 连接线实现 | `Branch` - 节点之间的连线 |
| `Command.py` | 命令模式 | `InsertNodeCommand`, `RemoveNodeCommand` 等 |
| `Component.py` | 组件模块 | `Note`, `Link`, `TodoList` 等 |
| `Config.py` | 配置常量 | 节点层级、命令ID等常量 |

5. **在 Graph.py 中添加设置优先级的方法**
```python
# Graph.py 中添加新方法
def setNodePriority(self, priority):
    """
    设置激活节点的优先级
    
    参数:
    - priority: 字符串，'high'、'normal' 或 'low'
    """
    if not self.m_activateNode:
        return
    
    # 创建命令上下文
    m_context = Context()
    m_context.m_activateNode = self.m_activateNode
    m_context.m_priority = priority
    m_context.m_scene = self
    
    # 创建命令（需要先在 Command.py 中创建 PriorityCommand）
    priorityCommand = PriorityCommand(m_context)
    self.m_undoStack.push(priorityCommand)
    
    self.messageShow.emit(self.tr('Info: Priority set to {} !'.format(priority)))
```

6. **在 Command.py 中添加优先级命令（支持撤销/重做）**
```python
# Command.py 中添加新命令类
class PriorityCommand(QUndoCommand):
    """
    修改节点优先级命令类
    """
    def __init__(self, context, *args, **kwargs):
        super(PriorityCommand, self).__init__(*args, **kwargs)
        self.context = context
        # 保存原始优先级
        self.old_priority = self.context.m_activateNode.m_priority
    
    def undo(self):
        """撤销：恢复原始优先级"""
        self.context.m_activateNode.m_priority = self.old_priority
        self.context.m_activateNode.update()
        self.context.m_scene.setActivateNode(self.context.m_activateNode)
    
    def redo(self):
        """重做：应用新优先级"""
        self.context.m_activateNode.m_priority = self.context.m_priority
        self.context.m_activateNode.update()
        self.context.m_scene.setActivateNode(self.context.m_activateNode)
```

```python
# Graph.py 的 nodeColor() 方法
def nodeColor(self):
    dialog = QColorDialog()
    # 如果节点有自定义颜色，使用节点颜色；否则使用默认颜色
    if self.m_activateNode.m_colorCustomized:
        dialog.setCurrentColor(self.m_activateNode.m_color)
    else:
        # 使用主题默认颜色
        if self.m_theme == 'Light':
            dialog.setCurrentColor(QColor(255, 182, 217))  # 粉色
        elif self.m_theme == 'Dark':
            dialog.setCurrentColor(QColor(70, 80, 120))   # 深蓝紫
        else:
            dialog.setCurrentColor(QColor(200, 200, 200)) # 灰色
```
